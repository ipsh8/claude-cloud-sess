# Ad Recreator

Turn a reference video’s storytelling and sales structure into an original video ad for your product.

## Invocation

Slash command `/marketing-adapt-video` on the Higgsfield MCP (`https://mcp.higgsfield.ai/mcp`, OAuth via Clerk), used from Claude, Codex or the ChatGPT plugin. The command's full workflow instructions are served by the MCP server after sign-in and are **not** included here; what follows is the public launch prompt verbatim.

```text
@Higgsfield

/marketing-adapt-video Create an original ad for my product using this reference video’s persuasion structure.

If the Higgsfield plugin is not installed, ask me to [install the Higgsfield plugin](https://chatgpt.com/plugins/higgsfield?open_in_app) before continuing.
```
