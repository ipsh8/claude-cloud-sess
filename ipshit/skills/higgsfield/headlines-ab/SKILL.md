# Headline Multiplier

Turn one static ad into multiple headline variations. Keep the visuals consistent so you can test different messages.

## Invocation

Slash command `/marketing-headline-variants` on the Higgsfield MCP (`https://mcp.higgsfield.ai/mcp`, OAuth via Clerk), used from Claude, Codex or the ChatGPT plugin. The command's full workflow instructions are served by the MCP server after sign-in and are **not** included here; what follows is the public launch prompt verbatim.
